# 🍔 麦麦饭搭子 (McDonald's Meal Buddy)

> 到饭点了，今天麦当劳怎么吃最划算？一句话告诉你。
> **更狠的是：它还能在「热量预算」内帮你挑——省钱 × 控卡，两个目标一起算。**

麦麦饭搭子是基于 [麦当劳中国 MCP 服务](https://open.mcd.cn/mcp) 与 [腾讯 WorkBuddy](https://www.workbuddy.cn) 开发的智能点餐决策助手。它不是优惠券列表——它把「营销活动日历 × 你的券包 × 当前时间 × 餐品营养数据」融合起来，直接给出**今天最划算（且可能最扛饿/最控卡）的一顿麦麦**。

## ✨ 核心能力

| 能力 | 说明 | 用到的 MCP 工具 |
|---|---|---|
| 🍟 **饭点推荐** | 综合时间/活动/你的券，给一句话点单决策 | `now-time-info` `campaign-calendar` `query-my-coupons` |
| 🥗 **热量预算搭餐**（差异化） | "500 大卡以内高蛋白吃什么"——从 160+ 款餐品营养数据里筛出最优解 | `list-nutrition-foods` |
| 🎫 **券包管家** | 我的券、有效期、临期预警 | `query-my-coupons` |
| 🪙 **一键薅券** | 麦麦省可领券一览 + 一键领取 | `available-coupons` `auto-bind-coupons` |
| 🧮 **算真账** | 指定门店选品→算含优惠实付价，"省 X 元"可验证 | `query-nearby-stores` `query-meals` `calculate-price` |
| 📅 **活动日历** | 未来一个月有哪些大促/新品，提前知道 | `campaign-calendar` |
| ⏰ **饭点自动化** | 每天 11:00 / 17:00 自动推送今日攻略 | WorkBuddy 自动化 |

## 🎯 与其他参赛作品的区别

麦当劳 MCP 实际开放了 **35 个工具**（不止网上流传的 5 个）。大多数作品停留在"查询+罗列"，麦麦饭搭子做的是**多源融合决策 + 营养维度**：

- 不只告诉你"有什么活动/有什么券"，而是**告诉你怎么点**
- 引入 **160+ 款餐品的营养数据库**，做到"省钱 × 控卡"双目标——这对减脂期还想吃麦麦的人是真需求
- 用 `calculate-price` 把"省了多少"变成**可验证的数字**，而不是嘴上说说
- 配合 WorkBuddy 自动化，饭点主动推送，不用你想起它

## 🖥️ 真实运行示例（数据均为 MCP 真实返回，见 [docs/demo-真实输出.md](docs/demo-真实输出.md)）

**输入**：今天麦当劳怎么吃最划算？（2026-10-11 19:36 调用）

**它做的事**：
1. `now-time-info` → 2026-10-11 19:36:17（周日）
2. `campaign-calendar` → 当日活动：超值 9.9 元早餐两件套（10/8–10/21）、韩式风味蘸酱上新、麦当劳 × PEACEMINUSONE 联名等
3. `query-my-coupons` → 卡包 2 张：新人专享-中杯美式 7 折（¥13.3，到店专用，有效期至 11/9）、中杯奶铁 7 折（¥14.7）
4. `list-nutrition-foods` → 160 款餐品营养数据，按"600 kcal 内高蛋白"筛选

**输出**：

```
🍔【麦麦饭搭子 · 明日早餐推荐】

👉 推荐：果然多肉（478 kcal，蛋白质 36.0g）

为什么：
· 现在是 2026-10-11 19:36，今日的「超值 9.9 元早餐两件套」活动进行中（10月8日—10月21日）
· 你卡包里 2 张新人券（中杯美式 7 折 / 中杯奶铁 7 折）都是「到店专用」，配早餐正合适
· 在 600 kcal 预算内，果然多肉的蛋白质密度最优，扛饿到中午

💰 省钱点法：早餐两件套 9.9 元 + 手里的中杯美式 7 折券（到店核销）
⏰ 提醒：两张新人券有效期至 2026-11-09，别放到过期
```

## 📦 安装方法

### 1. 获取麦当劳 MCP Token

1. 访问 [open.mcd.cn/mcp](https://open.mcd.cn/mcp)，右上角【登录】（手机号验证码）
2. 点击【控制台】→【激活】，同意服务协议
3. 复制生成的 MCP Token

### 2. 配置 MCP Server

在你的 MCP 客户端（WorkBuddy / Claude / Cursor 等）中加入：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn/mcp-servers/mcd-mcp",
      "headers": {
        "Authorization": "Bearer YOUR_MCP_TOKEN"
      }
    }
  }
}
```

> 🔒 `YOUR_MCP_TOKEN` 只保存在本地配置中，**切勿提交到公开仓库**。详见 [mcp-config.example.json](mcp-config.example.json)。
> WorkBuddy 用户：写入 `~/.workbuddy/mcp.json` 后，需在连接器管理中点击【信任】启用。

### 3. 安装本 Skill

将本仓库的 `SKILL.md`（及配套文件）放入你的 WorkBuddy 技能目录，对话中说「**今天麦麦怎么吃**」即可唤醒。

| 我有哪些券？快过期了吗？ | 券包管家 + 临期预警 |
