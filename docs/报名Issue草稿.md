**项目名称**：麦麦饭搭子（McDonald's Meal Buddy）

**项目地址**：https://github.com/tangquanliang/mcd-fanbuddy

**项目简介**：到饭点了，今天麦当劳怎么吃最划算？麦麦饭搭子基于麦当劳 MCP 的活动日历、优惠券与时间查询能力做多源融合决策——不是罗列优惠，而是直接告诉你今天这顿怎么点、省多少。支持一键领券、券到期防浪费提醒，配合 WorkBuddy 自动化还能在每天饭点自动推送「今日麦麦攻略」。使用腾讯 WorkBuddy 开发（附 workbuddy.md 对话上下文）。
