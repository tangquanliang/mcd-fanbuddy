## ③ 技术社区版（V2EX / 掘金 / CSDN 等，可发帖）

> 标题：用麦当劳官方 MCP + WorkBuddy 做了个"饭点决策"Skill：麦麦饭搭子
>
> 麦当劳程序员节开发大赛参赛作品。麦当劳开放平台提供了 5 个 MCP 工具（活动日历、麦麦省券列表、一键领券、我的券、时间查询），大多数参赛作品在做"查询罗列"，我做的是**多源融合决策**：
> - 编排「时间 × 活动日历 × 持有券」三元输入，输出一句话点单建议
> - 防浪费优先：今日到期券自动置顶，围绕它优化点法
> - 优惠叠加计算：券 × 活动的最大组合
> - WorkBuddy 自动化：每天饭点自动推送攻略
> 技术栈：WorkBuddy Skill + Streamable HTTP MCP + 提示词编排。开源了，欢迎 Star & PR：
